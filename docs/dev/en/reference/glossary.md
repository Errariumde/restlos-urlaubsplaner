# Glossary

The domain terms in German and English. UI texts, help, templates and code identifiers must use them.

| German | English | Meaning |
| --- | --- | --- |
| Soll | Required work | share of a day that would have to be worked; see [Required work](counting-model.md#required-work) and [Units](counting-model.md#units) |
| Genommen | Taken | share of the day taken off; see [Units](counting-model.md#units) |
| Restarbeitszeit | Work left | the required work of a day that no leave covers, own, mandatory or from another plan |
| Kontingent | Allowance | available leave days of a plan; see [Plan](file-format.md#plan) |
| Plan | Plan | period, allowance and selected days; see [Plan](file-format.md#plan) |
| Vertrag | Contract | rules of the employment; see [Contract](file-format.md#contract) |
| Plandatei | Plan file | file with one plan and its rules; see [Files](files.md) |
| Regelwerk | Rule set | file with the rules of a company or collective agreement, without a plan; see [Files](files.md) and [Rule sets](file-format.md#rule-sets) |
| Geräte-Einstellungen | Device settings | personal settings of one browser: language, display options and own color schemes; see [Kinds and versions](file-format.md#kinds-and-versions) |
| Arbeitswoche | Work week | required work per weekday, with validity; see [Work week](file-format.md#work-week) |
| Tagesregel | Day rule | own rule that lowers or fixes the required work or marks mandatory leave; see [Day rules](day-rules-format.md) |
| Kalenderquelle | Calendar source | named list of days (dates or repeating matches) with type and color; see [Calendar sources](file-format.md#calendar-sources) |
| Pflichturlaub | Mandatory leave | leave that charges the allowance automatically; see [Mandatory leave](counting-model.md#mandatory-leave) |
| Bezahlte Betriebsruhe | Paid closure | closure with required work 0 that costs nothing; see [Types](file-format.md#types) |
| Urlaub aus anderem Plan | Leave from another plan | leave charged in another plan, shown and not counted in this one; see [Leave from another plan](file-format.md#leave-from-another-plan) |
| Freizeit nötig | Time off needed | days or parts of days on which the user must be free, for example a Kita closure; see [Time off needed](file-format.md#time-off-needed) |
| Am Stück frei | Stretch | consecutive days off |
| Brückentag | Bridge day | working day between a holiday and the weekend |
| Sonderschalter | Local rule | regional exception, for example Augsburger Friedensfest; see [Local rules](holiday-data-format.md#local-rules) |
