# Repository files

The files for users and contributors in the repository root and in `.github/`.

| File | Content |
| --- | --- |
| `README.md` | short description; the project status notice, in German and in English |
| `SUPPORT.md` | a short hobby project notice; the issue templates for bug reports and ideas; no channel for general questions; security issues go to `SECURITY.md`; in German and in English |
| `CONTRIBUTING.md` | a short hobby project notice: no entitlement to review, reply or merge; process (larger changes discussed in an issue first, `npm run check` must pass, holiday data only with a link to the official source and a test); commits; language conventions; text in the repository; license of contributions (code, data and configuration EUPL-1.2, templates and examples MIT-0, documentation CC-BY-4.0); in English |
| `SECURITY.md` | private vulnerability reporting on GitHub; best effort, no deadline; where official releases are published |
| `CODE_OF_CONDUCT.md` | the project's own short code of conduct, with the Contributor Covenant as guidance; contributions that violate it are closed or deleted without discussion; in German and in English |
| `.github/ISSUE_TEMPLATE/` | `bug.yml`, a bug report with the required checkbox "I understand there is no commitment to reply or fix."; `feature.yml`, a feature request with the required checkbox "I understand ideas may be declined without explanation."; both in German and in English; `config.yml`: blank issues disabled, a link to private vulnerability reporting |
| `CHANGELOG.md` | changes per version, in the format "Keep a Changelog" |
