# Security

Please do **not** report vulnerabilities in public issues. Use GitHub's [private vulnerability reporting](https://github.com/errariumde/restlos-urlaubsplaner/security/advisories/new) (*Security* tab → *Report a vulnerability*).

Reports are handled on a best-effort basis, without any deadline.

Official releases are published only on [GitHub Releases](https://github.com/errariumde/restlos-urlaubsplaner/releases), with `SHA256SUMS` and build provenance. HTML files from other sources may contain malicious code.
